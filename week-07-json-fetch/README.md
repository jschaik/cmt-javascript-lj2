# Week 7 — JSON & fetch

## Theorie

In deze week leer je hoe je data laadt vanuit een JSON-bestand via `fetch`. Je werkt met promises (`.then()`) en leert hoe je JSON-data structureert en omzet naar HTML.

## Debug-opdrachten

In elke debug-map zit een kapotte fetch-app. Dit zijn korte, makkelijke opdrachten om foutmeldingen leren lezen.

1. Open de app in de browser
2. Lees de foutmelding in de console
3. Zoek de fout in de code
4. Fix de fout
5. Schrijf bovenaan `script.js`: `// Fout was: ...`

**Debug 4** is een stuk groter: een festival-app met negen fouten. Je zoekt elke foutmelding op op de [Foutmeldingen-pagina](https://meesterjson.nl/cheat-sheet/pages/javascript/foutmeldingen.html) van de cheat sheet en houdt een foutenlogboek bij in de README van debug-4.
